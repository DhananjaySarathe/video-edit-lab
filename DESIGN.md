# Video Edit Lab design

The application uses the Research Lab’s warm off-white canvas, forest-green controls, Newsreader headings and DM Sans interface text. A top format switch opens either Reels/Shorts or Long Form. A motion example introduces each format on a dark green panel.

A compact starter workflow leads into the library. Use edit stages for navigation and collections for selection within a stage. Each recipe names its example and use case. The edit builder stays alongside the library on wide screens and opens in a focus-managed dialog on smaller screens.
